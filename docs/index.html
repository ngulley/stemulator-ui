Two Repositories, One Platform

The platform is split into a React frontend and a Spring Boot REST API — each independently deployable.

⚛️
Frontend
stemulator-ui

React 18 + TypeScript + Vite SPA. Includes the Natural Selection simulation canvas, AI Science Coach chat, and a 4-step student lab workflow. Runs standalone with mock data — no backend required.

Backend API
stemulator-api

Spring Boot 3 REST API backed by MongoDB. Serves science lab data aligned with NGSS standards, and proxies GPT-4o-mini requests for the AI Science Coach and structured student evaluation features.

Get Started

Quick Setup

Get the platform running locally in minutes.

🖥 Frontend Only

Runs with built-in mock data. No backend needed. 

git clone https://github.com/ngulley/stemulator-ui.git
cd stemulator-ui
npm install
npm run dev
# → http://localhost:5173

🔗 Full Stack

Connect the API for live lab data and AI guidance. 

git clone https://github.com/ngulley/stemulator-api.git
cd stemulator-api
# Set OPENAI_API_KEY env var
docker run -d -p 27017:27017 mongo:7
./mvnw spring-boot:run
# → http://localhost:8080
